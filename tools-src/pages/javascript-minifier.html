How to minify JavaScript

  1. Paste your code into the left box, upload a .js file, or drop the file onto the box.
  2. Pick a mode. Minify for the smallest, fastest file; Obfuscate to hide your logic; Beautify to read minified code.
  3. Check the options. The defaults are safe for any script. If other scripts or inline onclick attributes call your functions, leave "Rename top-level names" off.
  4. Copy or download the result, and keep the original file for editing. Syntax errors show the line and column; select "Show in code" to jump there.

Minify vs uglify vs obfuscate

Comparison
FeatureMinifyObfuscate
GoalSmallest, fastest fileCode that is hard to understand
File sizeMuch smallerLarger than minified, often larger than the original
SpeedSame or fasterSlower, especially at high strength
Readable after Beautify?Mostly (local names are lost)No
Use it forEvery production scriptPaid widgets, licence checks, logic you do not want copied easily

"Uglify" is the older name for minifying, after UglifyJS. Terser is its maintained successor and supports modern JavaScript, so "uglify JS" and "minify JS" mean the same thing here.

Obfuscation costs size. The sample script above is {{JS_BEFORE}} bytes; obfuscated it becomes {{JS_OBF_LOW}} bytes at low, {{JS_OBF_MEDIUM}} at medium and {{JS_OBF_HIGH}} at high strength. Obfuscation is not encryption: never put passwords or API secrets in browser code.

Using minified JavaScript on Blogger and WordPress

Blogger

Blogger themes are XML, so minified code containing < or && stops the theme from saving. Tick Wrap for Blogger XML, copy the result and paste it in Theme → Edit HTML just before </body>. In a Layout → HTML/JavaScript gadget, paste a normal <script> block instead: gadgets are not parsed as XML.

WordPress

Upload the file to your child theme and load it with wp_enqueue_script() using the defer strategy, or paste the script into a header and footer plugin. If a caching or optimisation plugin already minifies JavaScript, do not minify the same file twice; turn one of them off.

Tip: minify, then add defer to scripts that do not need to run before the page appears. Check PageSpeed Insights before and after.
