How to create an HTML table

  1. Type or paste your data. Copy cells from Excel or Google Sheets and paste into the first cell, or use Import for CSV and Markdown.
  2. Mark the headers: header row for column titles, first column for row titles.
  3. Add a caption that says what the table shows; it helps screen readers and search engines.
  4. Choose a style. Tick Inline styles for Blogger or email.
  5. Copy the code and paste it into the HTML view of your editor.
