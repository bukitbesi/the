How to create a WhatsApp click-to-chat link

  1. Choose the country and type the number the way you normally write it. The tool converts it to international format.
  2. Add a message customers will send you, or pick a template. Use the buttons for bold and italic.
  3. Copy the link for your Instagram bio, Facebook page, TikTok profile or emails, and press Test link to check it.
  4. Download the QR code for posters, flyers, packaging and shop counters.
  5. Copy the button code for your website or Blogger.
