How to use the online notepad

  1. Start typing. The note saves itself; the first line becomes its title unless you type one.
  2. Keep several notes. New note adds one; the list and search box find them again. Open file imports .txt, .md or a backup.
  3. Format with Markdown and switch to Preview or Split to see it formatted.
  4. Use the tools: find and replace, case and line transforms, version history.
  5. Share or download. Share link copies a link that carries the note; Download saves TXT, Markdown, HTML or Word.

How the counts work

  • Words are runs of letters or digits in any script; isn't, e-mail and 3.5 count once.
  • Characters count what you see, so an emoji is one character, not two.
  • Sentences end with . ! or ? followed by a space or the end of the text.
  • Reading time uses 238 words per minute, the average silent reading speed for non-fiction in Brysbaert (2019).

Privacy and storage

Notes are stored with the browser's Web Storage on your device. This site has no account system and never receives your text. Share links keep the note after the #, which browsers do not send to servers; the note is only as private as the link. Private or incognito windows delete notes when closed, and clearing this site's data deletes them too, so keep backups of anything important.

Disclaimer: browser storage can be cleared by you, your browser or cleaning apps. Download a backup regularly; this tool is provided as is.
