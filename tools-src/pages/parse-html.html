Parse HTML: Escape, Encode and Decode

Paste code to parse (escape) HTML so it shows as text in a Blogger or WordPress post: < becomes &lt;, > becomes &gt; and & becomes &amp;. The same box encodes and decodes URLs, Base64, JavaScript strings and Unicode escapes, all in your browser.

How to parse HTML for a Blogger post

  1. Paste the code you want to show (HTML, CSS, JavaScript or an AdSense snippet).
  2. Keep HTML entities and Encode, and tick Wrap in a code block.
  3. Copy the output.
  4. In Blogger, open the post in HTML view and paste where the code should appear.
  5. Preview the post: the code shows as text, with spaces and line breaks kept.
