How to make a Blogger template with this generator

  1. Pick a brand colour. The generator builds the page, card, text, caption, border and link colours for light and dark mode, with a hint of your hue in the greys.
  2. Choose fonts and widths. Every font is a system font stack, so nothing extra downloads and text appears immediately.
  3. Add your menu and footer links as Label | URL, one per line. Links that start with / stay on your blog.
  4. Check the preview on a phone and a desktop, in light and dark mode, on the home page and a post.
  5. Read the contrast table. If a pair fails, press Fix contrast: only lightness changes, never the hue.
  6. Download the theme XML and install it in Blogger (steps below). The page address keeps your design, so you can come back to it.

How to install the template on Blogger

  1. In Blogger, open Theme in the left menu.
  2. Back up first: click More (the arrow at the top right), then Backup and Download.
  3. Open the same menu, choose Restore, click Upload and pick tbb-lite-custom.xml.
  4. Open Layout to check the menu, sidebar and footer widgets, and upload a logo in the Logo / blog title section if you have one.
  5. Later changes: Theme → Customize → Advanced lists all {{BT_VARS}} colours, fonts and widths.

Before you restore: a new theme replaces the old design. Posts and pages are safe, but widgets in sections the new theme does not have can be removed. Keep the backup and copy any HTML widget code you need. For a blog with many custom widgets, try the theme on a spare test blog first. This tool is not affiliated with Google or Blogger.
