HTML Beautifier, Formatter & Minifier

An HTML beautifier adds consistent indentation and line breaks so code is easy to read; an HTML minifier removes everything the browser does not need so pages load faster. This tool does both, with presets for websites, Blogger themes and emails, and checks your HTML for unclosed tags, missing alt text and other problems, with line numbers. How to beautify or minify HTML

  1. Paste your HTML into the left box, upload a file, or drop it onto the box. Whole pages, fragments and templates all work.
  2. Choose Beautify to make code readable, or Minify to make it small. For minifying, start with the preset that matches where the HTML will go.
  3. Read the HTML check under the result and select a line number to jump to each problem.
  4. Copy, download or preview the result. The preview runs with scripts disabled.

What the HTML checker finds

The checker reads your code as written, so every problem comes with the line where it starts. It follows the HTML rules browsers use: a new <li> closes the previous one, and <p>, <td> and similar elements may leave out their end tag without an error.

Why the Safe preset keeps one space

Whitespace between inline elements is visible. In <a>Home</a> <a>Blog</a> the space separates the links; remove it and they run together as "HomeBlog". The same happens between inline-block buttons and images. A minifier cannot know your CSS, so Safe collapses every run of whitespace to a single space instead of deleting it. That saves almost as much and never changes the layout. Maximum deletes it, which is only safe when your CSS uses flexbox or grid for those gaps.

Using it with Blogger, WordPress and email

Blogger

To read a theme, go to Theme → ⋮ → Edit HTML, copy everything and choose Beautify. To minify, choose the Blogger and XML preset, back up the theme first (Theme → ⋮ → Backup), then paste the result back and save. Keep the Variable definitions comment inside <b:skin>: the Theme Designer reads its <Variable> tags, so CSS inside CDATA is left unminified on purpose. For post HTML, Blogger's own editor reformats code when you switch views, so paste minified HTML in HTML view and publish without switching back.

WordPress

Beautify is useful for reading a theme template or the HTML of a block. To minify a live WordPress site, use your caching plugin's HTML minify option rather than editing theme files, so updates do not overwrite your changes.

Email

Gmail clips messages larger than about 102 KB and hides the rest behind "View entire message". The Email preset keeps Outlook's conditional comments and quoted attributes, which many email clients need.

Tip: fix every image the checker lists without width and height. It is one of the most common causes of a poor CLS score in PageSpeed Insights.
