Online Timer and Stopwatch

Set a countdown timer with an alarm, run a stopwatch with laps, or focus with a Pomodoro timer (25 minutes work, 5 minutes break) on one page. Press a preset from 1 to 60 minutes or type any time such as 5:00 or 1h30m. It keeps exact time in a background tab, and nothing to install.

    Example: cooking rice and a study session

    Rice needs 12 minutes: type 12 min or 12:00, label it "Rice" and press Start. The tab title counts down, so you can keep browsing. For revision, choose Pomodoro, keep 4 blocks of 25 minutes and press Start: the timer moves to each break and back with a short alarm, and rings longer at the end of the last block.

    How it keeps exact time

    1. End time, not ticks: pressing Start stores the exact finishing moment; the display shows the difference from the clock, so delays never add up.
    2. Background tabs: browsers slow down timers in hidden tabs; because the end time is fixed, the countdown is still right when you come back.
    3. Alarm: a separate check fires at the end time, beeps with the Web Audio API and vibrates phones that support it.
    4. Screen: while running, the page asks the browser to keep the screen on (Screen Wake Lock), and releases it on pause or reset.

    Popular uses

    • Classroom and exams: full-screen countdown on a projector for quizzes and presentations.
    • Exercise: stopwatch laps for running or plank holds; copy the laps into a spreadsheet.
    • Cooking: rice, eggs or kuih steaming with a label so you remember what the alarm is for.
    • Focus: Pomodoro blocks for study, work or typing practice with the Typing Test.

    Sources

    Note: Do not rely on a web page for safety-critical timing such as medication. Phones can suspend browsers when locked or on low battery; use a dedicated alarm for anything important.
