How to check color contrast

  1. Enter the text color and the background color, or pick them. Paste hex codes straight from your CSS or design tool.
  2. Read the ratio and the five WCAG results. Body text must pass AA normal (4.5:1).
  3. Click a suggested fix if it fails. It keeps your hue and changes only lightness.
  4. Check the color-blind preview and, for a design system, paste your whole palette.
  5. Copy the link to share the exact pair with your designer or client.

The contrast formula

Relative luminance L = 0.2126 R + 0.7152 G + 0.0722 B, where each channel is first linearised: c / 12.92 if c ≤ 0.04045, otherwise ((c + 0.055) / 1.055)^2.4, with c from 0 to 1. Contrast ratio = (L lighter + 0.05) / (L darker + 0.05).

Note: WCAG 3 is still a draft and proposes a different method (APCA). WCAG 2.2, used here, is the current W3C Recommendation and the standard most accessibility laws and audits refer to.
