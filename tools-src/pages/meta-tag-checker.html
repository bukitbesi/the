How to check your meta tags

  1. Type your title and description to preview them and see the character counts.
  2. For a full check, open your page and press Ctrl+U (or type view-source: before the address).
  3. Copy all the HTML and paste it into the box. The fields fill themselves and every check runs.
  4. Fix the red items first (noindex, missing viewport, broken JSON-LD), then the orange ones.
  5. Edit your title and description here until the preview reads well, then copy them into Blogger or WordPress.

Title and description lengths

Google's documentation says there is no limit on the length of a title element or a meta description; both are truncated as needed to fit the device width. The ranges below are common practice that usually shows in full, not Google rules.
