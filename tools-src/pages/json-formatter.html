Why big numbers get rounded

  
JavaScript, and most formatters built on JSON.parse, store every number as a 64-bit float, which holds whole numbers exactly only up to 9,007,199,254,740,991 (2^53 − 1). RFC 8259 warns about this. Order numbers, tweet IDs and bank references beyond that are silently changed: 12345678901234567890 becomes {{JF_BIG}}. This formatter reads numbers as text, so the output keeps every digit, and it warns you so you can store such IDs as strings.

  
Note: Fix JSON guesses what you meant. A missing comma or bracket can be fixed in more than one way, so always check the repaired data, and fix the program that produced broken JSON rather than repairing it by hand every time.
