How to add schema markup to your page

  1. Choose the type that matches the main content of the page: one article, one product, one recipe.
  2. Fill in the form with exactly what is visible on the page. Markup must match the page content.
  3. Fix the red items: they are properties Google requires. Orange items are recommended.
  4. Copy the script tag and paste it into the page's HTML (in the post body or before </head>).
  5. Test the live page in Google's Rich Results Test, then request indexing in Search Console.

Rich results Google no longer shows

  • FAQ: removed from Google Search on 7 May 2026 (limited to government and health sites since 2023).
  • HowTo: removed in 2023.
  • Book Actions, Course Info, Claim Review, Estimated Salary, Learning Video, Special Announcement, Vehicle Listing: phased out from June 2025.

The markup is still valid schema.org and does no harm; it simply no longer produces a special result in Google.

Rules: only mark up content visitors can see on the page, never invent reviews or ratings, and use one main type per page. Misleading structured data can lead to a manual action that removes your rich results.
