GitHub to jsDelivr Converter

Paste a GitHub file link to get a free jsDelivr CDN URL that browsers can load as a script or stylesheet: github.com/user/repo/blob/main/app.js becomes cdn.jsdelivr.net/gh/user/repo@main/app.js. You also get the minified version and a ready HTML tag.

How to use GitHub files as a CDN

  1. Upload the file to a public GitHub repository (CSS, JavaScript, fonts or theme images).
  2. Open the file on GitHub and copy the address from the browser bar.
  3. Paste it here and copy the jsDelivr URL or the ready HTML tag.
  4. For a live site, use a release tag or commit instead of a branch, so a change on GitHub cannot break your site and the file is cached forever.
  5. Paste the tag into Blogger (Theme, Edit HTML, before </head>) or your site's template.
