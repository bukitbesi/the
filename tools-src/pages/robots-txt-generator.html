How to make and test a robots.txt file

  1. Choose a preset and type your site address. Blogger and WordPress presets match each platform's own defaults.
  2. Adjust the rules. Each row is one Allow or Disallow line for a user agent; rows with the same agent become one group.
  3. Pick AI crawlers to block. "Block AI training only" stops training crawlers but keeps you visible in ChatGPT, Claude and Perplexity search.
  4. Read the audit and test your important URLs: a post, a label page, an image, your CSS. Fix anything blocked by mistake.
  5. Publish it at the root of your domain (not in a folder), then check it in Google Search Console's robots.txt report.

AI crawler user agents

Each company publishes the user agent tokens its crawlers obey. Training crawlers collect pages for model training; search crawlers index pages so they can be cited in AI answers; user-requested fetchers load a page when someone asks the assistant to read it, and some of them do not follow robots.txt.

How crawlers read robots.txt

These are the rules the tester applies, from RFC 9309 and Google's documentation. Every example is checked by the tool's own tests.

{{RB_EXAMPLES}}
Matching examples
RulesURLResult
  • One group per crawler. A crawler uses the group with the most specific matching user agent (Googlebot-Image falls back to Googlebot) and ignores the * group if a specific one exists. Groups for the same agent are merged.
  • Longest rule wins, whatever the order. On a tie, Allow wins.
  • Paths are case-sensitive; user agent names are not.
  • Limits: Google reads the first 500 KiB, caches the file for up to 24 hours and ignores Crawl-delay and Noindex lines.

Where to put robots.txt

Blogger

Settings → Crawlers and indexing → Enable custom robots.txt, then paste the file. Keep custom robots header tags off unless you know you need them. Blogger serves it at /robots.txt on your blog's domain.

WordPress

WordPress serves a virtual robots.txt until a real file exists. Upload robots.txt to the site root by FTP or the host's file manager, or use your SEO plugin's editor (Yoast: Tools → File editor; Rank Math: General Settings → Edit robots.txt).

Disclaimer: robots.txt is a request that reputable crawlers follow; it does not secure private content. Crawler names and behaviour change; this page lists tokens published by their operators as of {{RB_VERIFIED}}.
