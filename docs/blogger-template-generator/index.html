    How to make a Blogger template with this generator

    1. Pick a brand colour. The generator builds the page, card, text, caption, border and link colours for light and dark mode, with a hint of your hue in the greys.
    2. Choose fonts and widths. Every font is a system font stack, so nothing extra downloads and text appears immediately.
    3. Add your menu and footer links as Label | URL, one per line. Links that start with / stay on your blog.
    4. Check the preview on a phone and a desktop, in light and dark mode, on the home page and a post.
    5. Read the contrast table. If a pair fails, press Fix contrast: only lightness changes, never the hue.
    6. Download the theme XML and install it in Blogger (steps below). The page address keeps your design, so you can come back to it.

    How to install the template on Blogger

    1. In Blogger, open Theme in the left menu.
    2. Back up first: click More (the arrow at the top right), then Backup and Download.
    3. Open the same menu, choose Restore, click Upload and pick tbb-lite-custom.xml.
    4. Open Layout to check the menu, sidebar and footer widgets, and upload a logo in the Logo / blog title section if you have one.
    5. Later changes: Theme → Customize → Advanced lists all 18 colours, fonts and widths.

    Before you restore: a new theme replaces the old design. Posts and pages are safe, but widgets in sections the new theme does not have can be removed. Keep the backup and copy any HTML widget code you need. For a blog with many custom widgets, try the theme on a spare test blog first. This tool is not affiliated with Google or Blogger.

    <?xml version="1.0"?><html b:version='2' xmlns:b='http://www.google.com/2005/gml/b'><head>
<b:include data='blog' name='all-head-content'/><link rel='canonical' href='x'/>

<b:skin><![CDATA[body{}]]></b:skin></head><body></body></html>

    Blogger keeps one tag per b:if branch, so several canonical or description tags can still mean one per page; the audit asks you to check those instead of failing them. The only certain duplicate is a hand-written tag next to <b:include name='all-head-content'/>, because that include prints its own.

    Frequently asked questions

    Is this Blogger template really free?

    Yes. The generator outputs TBB Lite 1.0.1, an original theme released under CC BY 4.0: you can use and change it on personal and commercial blogs as long as the footer credit stays or you credit the author elsewhere on the blog. The file is 33.5 KB with no jQuery, web fonts or external scripts.

    How do I install the downloaded template on Blogger?

    First back up your current theme: in Blogger open Theme, click More (the arrow at the top right), then Backup and Download. Then use the same menu, choose Restore, click Upload and pick tbb-lite-custom.xml. Finally open Layout to check the menu, footer and sidebar widgets.

    Will I lose my posts if I change the template?

    No. A theme only controls the design; posts, pages, comments and labels stay where they are. Widgets in sections that the new theme does not have can be removed, so download the backup first and copy any HTML widget code you want to keep. Test on a spare blog if your current theme has many custom widgets.

    Why did the generator change my link colour?

    Links are text, so WCAG 2.2 AA needs 4.5:1 against every background they sit on. A bright brand colour often fails: yellow #ffeb3b on white is about 1.2:1, so the generator keeps it for buttons and borders and darkens only the link colour to #807300 (4.80:1), with #000000 button text. The hue never changes.

    What does the Blogger theme audit check?

    13 weighted checks that add up to 100: file size, render-blocking scripts in the head, jQuery, icon fonts, external stylesheets, duplicate canonical or meta description tags, the mobile viewport, article structured data, noindex on search and label pages, lazy-loaded images, layouts version 3 and b:css false. A typical older theme head scores 35; TBB Lite scores 100.

    Is my theme uploaded when I run the audit?

    No. The audit and the generator run entirely in your browser; the pasted XML never leaves your device. The only file this page downloads is the TBB Lite theme itself, from this site, to build your copy and the preview.

    Can I change colours and fonts later without this tool?

    Yes. All 18 settings are Blogger Theme Designer variables, so after installing open Theme, click Customize, then Advanced to change any colour, font or width. Values you chose here appear as the starting point, and the Reset button in Blogger returns them to your generated design.
