FAQ

Frequently asked questions

What is The Bukit Besi Tools?

The Bukit Besi Tools is a free directory of 49 browser-based tools published by The Bukit Besi, a Malaysian blog. It groups code minifiers, SEO generators, writing utilities, image editors, AI prompt tools and Malaysian calculators such as zakat and faraid into seven categories, with each tool opening on its own page.

Are all the tools really free to use?

The directory lists tools offered as free online tools. Check each tool page for available features, usage limits and any external services it uses.

Is my data safe? Do you store the code I paste?

This directory does not accept or process your code, text or images. Follow a tool link and check that tool page for how it handles input. Avoid pasting sensitive information unless you have verified its data handling.

Do I need to create an account?

You do not need an account to browse this directory. Each tool page explains any requirements for its features or external services.

Can I use the output for commercial projects?

Check the relevant tool and any external service terms before using output commercially. Review generated code, documents and images before publishing them.

Which tools help improve Core Web Vitals and page speed?

The JavaScript Minifier and CSS Minifier can reduce code size, and the Image Format Converter can help prepare smaller images. Results depend on the original files and how your site loads them; use PageSpeed Insights to measure your page before and after changes.

Which platforms work with these tools?

The output is plain HTML, CSS, JavaScript, JSON and images, so it works on Blogger, WordPress, Shopify, Wix, custom HTML sites and frameworks such as React and Vue.

Can I install the directory as an app or use it offline?

Yes. The directory is a progressive web app, so supported browsers can install it from the Install app button or the browser menu. After one online visit, the tool list, categories and descriptions open offline; the tools themselves still need an internet connection.

Will more tools be added?

Yes. New tools are added regularly and this page is updated each time a tool goes live.

How can I suggest a new tool?

Use the contact page on The Bukit Besi blog and describe the tool you need. Requests from readers are reviewed.
