FAQ

Frequently asked questions

Are all the tools really free to use?

Yes. Every tool listed on this page is free to use with no subscription, no paywall and no usage limit.

Is my data safe? Do you store the code I paste?

The tools are built to run in your browser, so the code, text and images you work with are processed on your own device rather than being uploaded for storage. Each tool page states how it handles your input.

Do I need to create an account?

No. There is no account, email or login. Open a tool and start using it.

Can I use the output for commercial projects?

Yes. Minified code, converted images, generated schema and other output are yours to use in personal or commercial projects.

Which tools help improve Core Web Vitals and page speed?

The JavaScript Minifier, CSS Minifier and HTML Minifier reduce file size so pages download and parse faster, and the Image Converter can turn heavy JPG or PNG files into lighter formats such as WebP. Smaller assets typically improve Largest Contentful Paint (LCP) and Lighthouse performance scores.

Which platforms work with these tools?

The output is plain HTML, CSS, JavaScript, JSON and images, so it works on Blogger, WordPress, Shopify, Wix, custom HTML sites and frameworks such as React and Vue.

Will more tools be added?

Yes. New tools are added regularly and this page is updated each time a tool goes live.

How can I suggest a new tool?

Use the contact page on The Bukit Besi blog and describe the tool you need. Requests from readers are reviewed.
